These are public engineering summaries of selected projects. Some underlying repositories are intentionally private, so these pages focus on the problem, architecture, decisions and lessons rather than publishing proprietary code or credentials.

## Why case studies?

A repository can show code. A case study can show the engineering thinking around the code: what problem existed, where the boundaries were drawn, what tradeoffs mattered and how the system moved toward real use.
